### 🛡️ [VulnShop — IT Security Lab](https://github.com/sackokalil/Vulnshop-IT-Security)

VulnShop is an intentionally vulnerable e-commerce web application developed as part of an IT Security project. It combines a simplified online shop with an integrated Security Lab to demonstrate common web application vulnerabilities, illustrate how they can be exploited, and present basic mitigation techniques in an educational environment.

`Python` · `Flask` · `SQLite` · `Selenium` · `HTML` · `CSS` · `JavaScript` · `OWASP Top 10`

<details>
<summary><strong>View security coverage</strong></summary>

- Union-based, authentication-bypass, and blind SQL injection
- Stored and reflected cross-site scripting (XSS)
- Broken authentication and insecure password reset
- IDOR and broken access control
- Path traversal, CSRF, and insecure file upload
- Automated exploit demonstrations and mitigation guidance

</details>

Mini compiler/interpreter project developed in Python in the context of Compiler Construction (Compilerbau).

The project implements the complete compilation pipeline for arithmetic expressions.

`Lexer` → `Recursive Descent Parser` → `Abstract Syntax Tree` → `Intermediate Code` → `Virtual Stack Machine`

<details>
